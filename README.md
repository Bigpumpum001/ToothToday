# 🦷 ToothToday
ระบบจองคิวทันตกรรมออนไลน์

ToothToday เป็นระบบจองคิวทันตกรรมที่ออกแบบและพัฒนาด้วยตัวเองตั้งแต่ต้นจนจบ เพื่อจำลองการทำงานของคลินิกจริง เน้นประสบการณ์ผู้ใช้ที่ง่ายและรวดเร็ว พร้อมฟังก์ชันครบถ้วนสำหรับทั้งผู้ใช้ทั่วไปและผู้ดูแลระบบ

## 🚀 ฟีเจอร์หลักที่พัฒนา

### 👤 ผู้ใช้งานทั่วไป
- 📝 ลงทะเบียน / เข้าสู่ระบบ
- 📅 จองคิว (เลือกบริการ, วันที่, เวลา, แพทย์, Upload รูป, หมายเหตุ)
- ℹ️ รายละเอียดบริการและแพทย์, วิธีการจองคิว, ตารางคิวแพทย์, สถานะของวัน, เวลา, แพทย์ที่ต้องการจอง
- 🧾 หน้า Profile แสดงข้อมูลส่วนตัว, ประวัติการนัดหมาย, เชื่อมต่อ LINE, ยกเลิกการจอง

### 🕒 ระบบการจัดการ Slot และเวลา
- 🎨 หน้า Booking Page มีสีบอกสถานะ เช่น วันนั้น ว่าง, ใกล้เต็ม, เต็ม, หรือ ปิด
- ⏱️ Slot ของแต่ละแพทย์แบ่งเป็น 1 ชั่วโมง เพื่อให้สามารถดูแลผู้ป่วยได้เต็มที่ พร้อมเวลาเตรียมห้องและพักระหว่างคิว

### ⏰ การจองเช็คเวลาตามระยะเวลาบริการ
ตัวอย่างสถานการณ์:  
สมมุติสถานะ slot: `[08:00 ว่าง] [09:00 ไม่ว่าง]` (ข้อมูลจาก DB)
- ⏳ เลือกบริการ 1 ชั่วโมง ที่ `[08:00]` → สามารถจองได้
- ⏳ เลือกบริการ 1 ชั่วโมง 20 นาที → ระบบปัดเป็น 2 ชั่วโมง → ไม่สามารถจองได้ เพราะ slot `[09:00]` เต็ม
- ⏳ หากเลือกเวลาจอง เช่น slot 08:00 และมีแพทย์ 2 คน:
  - หากแพทย์คนใดคนหนึ่งว่าง → สามารถจองได้
  - หากแพทย์ทุกคนเต็ม → ระบบจะแสดงว่า slot นั้นเต็ม

### ⚙️ Job อัตโนมัติ
- ⏲️ หากผู้จองไม่มายืนยันภายใน 10 นาทีของ slot → คืน slot ให้เปิดรับ walk-in
- ✅ Slot ที่อยู่ระหว่างการเข้ารับบริการจะถูกมาร์คว่า complete หลังสิ้นสุดการรักษา

### 📜 ประวัติการนัดหมาย
- 🕑 ดูได้ทั้งนัดหมายปัจจุบันและอดีต
- ❌ สามารถยกเลิกได้ถ้ายังไม่ถึงเวลา

### 📩 แจ้งเตือนผ่าน LINE
- 🔗 เชื่อมต่อ / ยกเลิกการเชื่อมต่อ LINE
- 📌 แจ้งเตือนจองคิวสำเร็จ / ยกเลิกคิว
- ⚠️ แจ้งเตือนผู้ไม่มาภายใน 10 นาที / แจ้งเตือนบริการสำเร็จ
- ⏰ แจ้งเตือนล่วงหน้า 1 ชั่วโมง / 24 ชั่วโมง

### 🔒 ระบบความปลอดภัย
- 🔑 Authentication ด้วย JWT
- 🔒 Password เข้ารหัสด้วย bcrypt
